# Арабикос — GitHub Pages

Статическая версия: 22 урока по 10 слов, 180 предложений только из изученных слов, карточки с интервальными повторениями, сборка трудных слов из букв и харакатов, трекер и мягкие звуки ответов. Арабский шрифт — Noto Naskh Arabic.

«Помню» / «Не помню» доступны до переворота. Нажатие на карточку показывает перевод. После ответа ненадолго появляется только перевод, затем следующая карточка. Свайпов нет. Правильный ответ в проверке сразу открывает следующий вопрос. Авторизация и обращения к серверу прогресса отсутствуют. В настройках можно экспортировать и импортировать прогресс; старые копии курсов из 10 и 20 уроков поддерживаются.

Прогресс хранится в localStorage текущего браузера под ключом `arabikos-progress-v2`. Другой браузер/устройство имеет свой прогресс. Очистка данных сайта удаляет результаты. Прогресс прежней версии на Sites автоматически не переносится; её серверные данные остаются без изменений.

## Сборка

Зависимости и lockfile находятся в соседней папке `sites-app`:

```sh
cd sites-app
npm ci
cd ..
```

Для сборки `pages-app` нужно, чтобы React, React DOM, lucide-react, Vite и @vitejs/plugin-react были доступны в родительском node_modules (например, символической ссылкой на sites-app/node_modules). Команда из корня:

```sh
node sites-app/node_modules/vite/bin/vite.js build --config pages-app/vite.config.ts
```

Содержимое `pages-dist` копируется в корень репозитория, включая скрытый `.nojekyll`. GitHub Pages публикует main / root. `sites-app` содержит серверную версию и не является точкой входа Pages.

`sw.js` выводит из эксплуатации кэш старой версии, не изменяя localStorage.

«Трудные слова» включает только слова с сохранённым ответом «Не помню» (или ненулевым счётчиком таких ответов), пока они не собраны без подсказки. Показанная и затем скрытая подсказка всё равно считается использованной. Успешная сборка не меняет срок карточки; новый ответ «Не помню» возвращает слово в трудные. Состояние сохраняется в браузере и в резервной копии. В словаре слева кнопка трудных слов, справа — карточек.

«Практика» — меню тестов: предложения и глаголы (после урока 8). Раздел «Глаголы» предлагает выбор из изученных глаголов, сначала знакомит с девятью формами изученного глагола, затем проверяет выбор времени и лица. Новые корни доступны только после завершения соответствующего урока. Варианты неправильного ответа относятся к тому же глаголу.

Проверка логики форм и отбора трудных слов из корня проекта: `node pages-app/tests/verb-forms.cjs`.

Алфавит: приветствие в новом браузере предлагает изучить 28 букв или скрыть раздел. Ранее сохранённые занятия продолжаются без этого экрана. Алфавит можно открыть в настройках. Формы букв учитывают шесть букв, не соединяющихся со следующей буквой. Тест предлагает четыре формы в одной позиции, сохраняет правильные ответы и возобновляется с оставшихся букв. Статус и освоенные буквы включаются в экспорт прогресса; прежние файлы совместимы. Произношение названий использует только доступный арабский голос Web Speech API устройства, без платных сервисов; при отсутствии голоса доступна транскрипция. Общий переключатель звука управляет и озвучкой.

Проверка: `node pages-app/tests/alphabet.cjs`, `node pages-app/tests/verb-forms.cjs`, TypeScript и сборка Vite. Тест интерфейса использует модель React hooks, а не визуальную проверку в браузере.

Дополнительные предложения находятся в `lib/practice-examples.ts`. Каждый токен ссылается на точный ID изученной формы, включая падежные формы после предлогов и формы прямого дополнения. Два новых урока дают бытовую речь о доме, работе и еде; прежние уроки и ID сохранены. Прежний завершённый курс из 20 уроков продолжится с урока 21. Проверка переходов, подсказок, резервной копии и строгого словаря: `node pages-app/tests/practice-and-difficult.cjs`.

Пройденные уроки скрыты из текущего списка и доступны во вкладке архива со словами и примерами. Просмотр архива не меняет урок или шаг прогресса. Предложения перемешиваются внутри групп по самому позднему уроку, необходимому для фразы; группы идут от новых к старым. Порядок закреплён на сессию и обновляется при новом запуске или повторении. Глаголы сгруппированы по пройденным урокам; все 10 глаголов урока 8 включены. В уроках 1–7 глаголов нет.
