# Арабикос — Мединский курс, том 1, уроки 1–5

Пять интерактивных адаптаций первых тем «Дурус аль-луга аль-арабийя» доктора В. Абдур-Рахима. Источник: https://abdurrahman.org/wp-content/uploads/2014/01/madina-book-1-arabic-text-dr-v-abdurrahim.pdf (печатные страницы 6–31). Учебник просмотрен как скан; страницы и иллюстрации не опубликованы в приложении. Русские пояснения и задания подготовлены для приложения по темам и изученной лексике.

Темы: هذا и вопросы; ذلك и وَ; определённый артикль и описание; предлоги и местонахождение; идафа. 112 слов и учебных форм, 95 уникальных предложений. После предлогов и в идафе вводятся отдельные точные формы окончаний. В уроке 4 — два глагола: ذَهَبَ и خَرَجَ, только известная форма «он» в прошедшем времени. Настоящее, будущее и другие лица в этой версии не добавлены раньше программы.

Главная — путь пяти уроков с декоративными розетками, автопрокруткой, лучшими результатами и повторным прохождением. Темы и правила по-русски, названия и примеры по-арабски с огласовками. Число слов разное, поэтому шаги урока динамические: словарь + 3 примера + 10 заданий. Все предложения проверены по ID форм и уроку введения. أَ и وَ при показе полного предложения соединяются со следующим словом.

Сохранение нового курса: arabikos-madinah-v1. Прежнее arabikos-progress-v2 не очищается и не перезаписывается; из него переносятся только история дней и состояние алфавита. Старые уроки не считаются пройденными в новом учебнике. В настройках можно скачать прежнее сохранение. Новые резервные копии имеют version:2 и course:madinah-book1-v1; старые копии не импортируются под другими словарными ID. Темы, звук, направление карточек и текущий URL остаются прежними.

Офлайн-оболочка генерируется Vite с перечнем файлов и хешем сборки. Чтобы установить ожидающую версию, откройте настройки → «Установить обновление». История и карточки хранятся в localStorage, приложение — в Cache Storage. Напоминание 20:00 МСК — через экспорт события календаря. Собственный сервер push пока не подключён.

Сборка из корня: node node_modules/vite/bin/vite.js build --config pages-app/vite.config.ts.
Проверки: madinah-course.cjs, path-and-lesson-ui.cjs, alphabet.cjs, offline-worker.cjs (после сборки). Проверка интерфейса моделирует React hooks; реальный iPhone не использовался. Содержимое pages-dist публикуется в корень репозитория на GitHub Pages.
