# Арабикос — GitHub Pages

Новая статическая версия: 10 уроков по 10 слов, строгий словарь предложений, карточки с интервальными повторениями, трекер и звуки ответов.

«Помню» / «Не помню» доступны до переворота. Нажатие на карточку показывает перевод. Правильный ответ в проверке сразу открывает следующий вопрос. Авторизация и обращения к серверу прогресса отсутствуют.

Прогресс хранится в localStorage текущего браузера под ключом `arabikos-progress-v2`. Другой браузер/устройство имеет свой прогресс. Очистка данных сайта удаляет результаты. Прогресс прежней версии на Sites автоматически не переносится; её серверные данные остаются без изменений.

## Сборка

Зависимости и lockfile находятся в соседней папке `sites-app`:

```sh
cd sites-app
npm ci
cd ..
```

Для сборки `pages-app` нужно, чтобы React, React DOM, lucide-react, Vite и @vitejs/plugin-react были доступны в родительском node_modules (например, символической ссылкой на sites-app/node_modules). Команда из корня:

```sh
node sites-app/node_modules/vite/bin/vite.js build --config pages-app/vite.config.ts
```

Содержимое `pages-dist` копируется в корень репозитория, включая скрытый `.nojekyll`. GitHub Pages публикует main / root. `sites-app` содержит серверную версию и не является точкой входа Pages.

`sw.js` выводит из эксплуатации кэш старой версии, не изменяя localStorage.
