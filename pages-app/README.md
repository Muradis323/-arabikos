# Арабикос

React/TypeScript приложение по темам Мединского курса: 23 цельных урока первого тома, итоговый экзамен и первые пять уроков второго тома. Собственные короткие примеры и тесты; приложение является учебной адаптацией, а не электронной копией всех страниц учебника.

## Учебный материал

- Том 1: уроки 1–23; итоговое повторение, цвета и окончания слов, не принимающих танвин.
- Экзамен: 24 вопроса по первому тому. Проходной результат — 80 баллов (20 верных ответов). Незавершённая попытка сохраняется; успешная сдача открывает том 2. Неудачная повторная попытка не закрывает уже открытый том.
- Том 2: 1) إِنَّ и لَعَلَّ; 2) لَيْسَ; 3) сравнение и числа 11–20; 4) прошедшее время; 5) действующее лицо и прямое дополнение.
- Все учебные слова, варианты и примеры — с огласовками. Предложения используют слова текущего и предыдущих уроков, максимум семь учебных токенов. В практике первые пять предложений содержат слова последнего завершённого урока; всего — пять заданий на каждый пройденный урок, до 140.
- Раздел глаголов удалён из приложения. Глаголы изучаются в уроках и обычных карточках.

## Прогресс

Ключ `arabikos-madinah-v1` и идентификатор курса `madinah-book1-v1` сохранены. Первые 297 ID слов и номера 20 прежних уроков не меняются. Старое завершение 20 уроков переводит на урок 21, сохраняя карточки, баллы и попытки. Формы артикля и падежа используют одну словарную запись; исходные интервалы не удаляются.

Резервная копия v3 включает экзамен, ошибки, попытки уроков, слова рассказов, закладки и недельные завершения. Импорт v2 поддерживается. Ручное восстановление уроков второго тома требует сданного экзамена. Цель — два разных полных урока в неделю; повторное прохождение считается. Дневная серия — отдельная необязательная статистика.

Устаз имеет восемь эмоций и жестов. Приветствие — поднятая рука при прямом положении корпуса. Нажатие меняет эмоцию. `prefers-reduced-motion` выключает анимацию. Тема «Неон» хранится в `arabikos-palette`; настройки открыты по умолчанию.

## Проверка и сборка

Из корня проекта:

```sh
npm ci
npm run build
npm test
npm run test:offline
# С запущенным npm run dev -- --port 4173:
npm run test:browser
```

Сборка — `pages-dist`. Для GitHub Pages публикуются её `index.html`, `sw.js` и файлы `assets`, указанные в новом HTML. Предыдущие хешированные файлы не удаляются: они нужны клиентам с открытой предыдущей версией. Ожидающий service worker активируется кнопкой «Установить обновление».

## Чтение из загруженной книги

`content/adhkar-opening.txt` — обложка и первая основная глава целиком, страницы 15–19 книги «الذِّكْرُ وَالدُّعَاءُ فِي ضَوْءِ الْكِتَابِ وَالسُّنَّةِ». Все предисловия пропущены. Хадисы 1–8, пояснения и сноски сохранены; разрывы оригинала внутри цитат объединены. Добавлены огласовки. Постраничная раскладка сохраняет аяты с вводной строкой и ссылкой, а длинную прозу делит по знакам препинания. Перелистывание справа налево (свайп по свободному месту, стрелки или клавиатура). Перевод привязан к слову, ведение пальцем по словам меняет перевод; флажок добавляет в словарь. Старые карточки и закладки сохранены. `content/adhkar-glossary.tsv` содержит переводы всех словоформ. Сборщик отказывается выпускать данные с непереведёнными арабскими словами или незакрытыми цитатами:

```sh
python pages-app/scripts/build-adhkar.py
```

В интерфейсе — прямое чтение, перевод выбранного слова и флажок. Оглавление рассказов и инструменты каждого абзаца удалены. Место чтения сохраняется автоматически; прежние закладки и слова остаются в прогрессе. Повторное сохранение слова с другим падежным окончанием не сбрасывает его интервал.

В настройках один раздел прогресса, один выбор источника (уроки, файл, автокопия) и одна кнопка применения.

## Дневная шкала и простой вход

Приложение сразу открывает полный путь уроков и прокручивается к текущему. Приветствие, алфавит, недельный блок и общий блок прогресса убраны из интерфейса. Старые данные обучения сохранены. Настройки — три обычных секции: темы, звук/тактильный отклик, восстановление.

`lib/daily-points.ts`: дневная цель 60 баллов, слово = 1, полное предложение = 3, четыре пары = 4. В уроках награда начисляется при переходе с изученного слова/примера или завершённого правильного задания (включая последнее). Правильные карточки, слова чтения, аудирование и сборка слова дают по 1; предложение в практике — 3. Неверный ответ не даёт баллов. Двойное нажатие на тот же шаг не начисляет награду повторно. `dailyPoints` хранится по местной календарной дате вместе с существующим прогрессом и входит в экспорт/импорт; на новый день отображается новая шкала без удаления истории. Старые файлы без этого поля поддерживаются. Процент результата урока остаётся оценкой точности, отдельной от дневных баллов.

## Единый словарь

`lib/unified-dictionary.ts` объединяет пройденные слова курса и сохранённые слова чтения/ручного ввода в один список и очередь карточек. Совпадающие арабские формы с артиклем и огласовками отображаются один раз; существующие исходные записи не удаляются. При объединении используется наиболее отработанное расписание повторений, а новый ответ синхронизируется по всем связанным записям. Архив исключён из общей очереди, восстановление из архива сохраняет интервалы. Флажок книги сразу добавляет слово в общий словарь; отдельного раздела и отдельной практики слов чтения в интерфейсе нет. Ручной ввод требует арабское слово и перевод, проверяет дубли и сохраняет запись сразу для карточек. Старые `reading.cards` автоматически видны без переноса/удаления; резервные копии сохраняют архив и ручные слова. Источник хранения остаётся совместимым с прежними версиями и уроками.


## Книжная полка и «40 хадисов ан-Навави»

В практике оставлены «Предложения» и новая книга хадисов. Прежние записи азкаров, рассказы и сохранённые слова не удаляются, но их переходов на полке нет. Данные первых пяти хадисов: `lib/nawawi-book.ts`, источники: `content/nawawi-sources.md`, обложка: `content/book-covers.md`.

`NawawiReader.tsx` показывает разворот от 1100 px и одну страницу на меньшем экране. `lib/nawawi-pages.ts` делит текст без потерь; закладка хранит индекс страницы, независимый от ширины экрана, в `reading.bookmarks['nawawi-forty-v1']`. Касание, ведение по словам и клавиатура открывают перевод над словом; флажок сохраняет его через общие функции `lib/reading-words.ts`. Полный смысловой перевод и источник доступны для каждого хадиса видимого разворота. Размер шрифта сохраняется в существующем `reading.font`.

Браузерные проверки охватывают 390/1440 px, обложку, касания, свайп, клавиатуру, подсказки, словарь, закладки, крайние страницы и тёмную/неоновую темы. `npm test` запускает модульные регрессии, отдельно `npm run test:offline` проверяет собранный service worker. Публикация сохраняет предыдущие хешированные ресурсы и старый localStorage.
