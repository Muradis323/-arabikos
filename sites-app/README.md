# Арабикос — новая версия

Работающее приложение: https://arabikos.muradis.chatgpt.site

- 10 последовательных уроков по 10 слов с полными огласовками.
- 30 учебных предложений: точные формы только из текущего и предыдущих уроков.
- Проверка знаний перед добавлением слов в словарь.
- Карточки со свайпами и интервальным повторением.
- Личный прогресс в Cloudflare D1, отдельный для каждого вошедшего пользователя.
- Книжное оформление и шрифт Amiri Quran.

## Запуск и сборка

Требуется Node.js 22.13+.

```sh
npm ci
npm run dev
npm run build
```

Используются React, TypeScript, Vinext и Cloudflare Workers. Для полноценной работы нужны привязка D1 `DB`, миграции из `drizzle/` и идентификация посетителя через Sites / Sign in with ChatGPT. Самостоятельный локальный запуск без этих сервисов позволяет работать с исходниками, но не заменяет сервер хранения прогресса.

GitHub Pages не исполняет API и D1 этого приложения. Публичная рабочая версия размещена в Sites по ссылке выше. Коммит в GitHub сам по себе её не обновляет: после изменений требуется публикация в Sites.

## Содержание

`lib/course.ts` — слова, переводы, предложения и интервалы повторения. Предложения содержат ID слов, проверяемые `validateCourse()`. Это учебные фразы, а не цитаты из Корана.

`app/page.tsx` — интерфейс. `app/api/progress/route.ts` — чтение и сохранение личного прогресса. `db/schema.ts` и `drizzle/` — схема и миграции.

## Разделение данных

API принимает личность только из проверенного Sites-контекста. Анонимные запросы получают 401. Каждая запись принадлежит отдельному идентификатору пользователя. Параллельное сохранение защищено номером ревизии. Старый прогресс владельца переносится однократно при совпадении проверенной почты с серверной переменной `LEGACY_OWNER_EMAIL`; значение не хранится в исходниках.

Рабочие базы, пользовательский прогресс, секреты и зависимости в репозиторий не включены.
