# Арабикос

Актуальная версия публикуется через GitHub Pages из корня ветки main.

- 20 интерактивных уроков по темам первого тома Мединского курса, предложения строго из текущего и завершённых уроков.
- Урок открывается нажатием на кружок пути; пройденные уроки можно повторять.
- Глаголы доступны в практике сразу после изучения соответствующего слова, включая незавершённый урок. Первые глаголы курса встречаются в уроке 4.
- Правильный ответ сразу переключает задание; выбор, сборка слов и предложений, соединение пар. Звуки и тактильные сигналы можно выключить.
- «Помню / Не помню» доступны без переворота; перевод открывается нажатием.
- Интервальное повторение, словарь и трекер.
- Свайп слова влево раскрывает действие «Изучено». Отмеченные слова сохраняются в отдельной вкладке и исключаются из карточек и трудных слов; их можно вернуть без сброса истории повторений. Отметки входят в резервную копию.
- Направление карточек переключается ползунком. Каждый урок содержит 24 теста, включая повторение слов предыдущих уроков.
- Прогресс сохраняется в текущем браузере. Авторизация не нужна.
- Расширение с 5 до 20 уроков сохраняет идентификаторы первых слов, баллы и сроки повторения; после завершённого пятого урока открывается шестой.

**Важно:** другой браузер или устройство имеет отдельный прогресс. Очистка данных сайта удалит результаты.

Исходники: [pages-app](./pages-app). Готовая сборка: index.html и assets в корне. Серверная версия Sites сохранена отдельно в [sites-app](./sites-app).

Если браузер показывает старую версию, откройте настройки и установите обновление. Обновление service worker удаляет только старый кэш, не данные localStorage.
