# Арабикос

Актуальная версия публикуется через GitHub Pages из корня ветки main.

- 10 уроков по 10 слов, предложения строго из текущего и завершённых уроков.
- Правильный ответ сразу переключает задание, есть звуки с выключателем.
- «Помню / Не помню» доступны без переворота; перевод открывается нажатием.
- Интервальное повторение, словарь и трекер.
- Прогресс сохраняется в текущем браузере. Авторизация не нужна.

**Важно:** другой браузер или устройство имеет отдельный прогресс. Очистка данных сайта удалит результаты.

Исходники: [pages-app](./pages-app). Готовая сборка: index.html и assets в корне. Серверная версия Sites сохранена отдельно в [sites-app](./sites-app).

Если браузер показывает старую версию, обновите страницу. Обновление service worker удаляет только старый кэш, не данные localStorage.
