# Арабикос

Актуальная версия публикуется через GitHub Pages из корня ветки main.

- 23 урока первого тома Мединского курса, итоговый экзамен и пять уроков второго тома.
- Практика — книжная полка с двумя книгами: «Предложения» и «40 хадисов ан-Навави». Аудирование, глаголы и прежнее чтение на полке не показываются; ранее сохранённые слова и закладки остаются в прогрессе.
- Первые пять хадисов целиком: 423 слова с контекстным переводом по удержанию 0,5 секунды, смысловой перевод и ссылки на источники. Русская обложка, предоставленная пользователем, страницы под старую бумагу, анимация перелистывания, разворот на компьютере и одна страница на телефоне.
- Удержание слова 0,5 секунды показывает перевод над ним. Обычные касания и вертикальная прокрутка не открывают перевод. Флажок добавляет слово в общий словарь без дублей. Книга читается справа налево; свайп вправо листает вперёд, влево — назад. Работают стрелки, клавиатура, оглавление и автоматическая закладка.
- «Предложения» сохраняют задания, подборки по пройденным урокам и место в подборке. До первого завершённого урока показывается понятная подсказка.
- Устаз — робот-учитель с эмоциями и жестами. При ограничении анимации в настройках устройства движения отключаются.
- Единый словарь, интервальное повторение, архив слов, дневная цель и резервная копия. Ключ и формат прежнего прогресса сохранены.
- Пять цветовых тем, тёмный режим, звук и тактильный отклик. Авторизация не нужна; после загрузки сборка и обложка доступны без сети.

## Разработка

```sh
npm ci
npm run build
npm test
npm run test:offline
npm run dev -- --port 4173
# В другом терминале, с запущенным сервером:
npm run test:browser
```

Сборка находится в `pages-dist`. Для публикации GitHub Pages копируются `index.html`, `sw.js` и новые файлы из `assets` в корень репозитория. Старые хешированные файлы сохраняются для клиентов предыдущей версии. Ожидающий service worker устанавливается из настроек приложения.

**Важно:** другой браузер или устройство имеет отдельный прогресс. Очистка данных сайта удалит результаты.

Исходники: [pages-app](./pages-app). Готовая сборка: index.html и assets в корне. Серверная версия Sites сохранена отдельно в [sites-app](./sites-app).

Если браузер показывает старую версию, откройте настройки и установите обновление. Обновление service worker удаляет только старый кэш, не данные localStorage.
