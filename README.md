# Арабикос

Статический учебный сайт для изучения арабского языка Корана. Работает без сборщика и подходит для GitHub Pages.

## Что уже есть

- Алфавит из 28 букв.
- Словарь с огласовками, корнями, типами слов и уровнями.
- Система прогресса в `localStorage`.
- Новые слова открывают задания в других разделах.
- Тест «Собери предложение».
- Тест на определение формы глагола.
- Раздел предлогов с примерами падежных окончаний.
- Правила, которые открываются по мере роста словаря.
- Короткие учебные рассказы, листающиеся как книга.
- Крупный арабский шрифт и современный русский интерфейс.
- Старая книжная стилистика без картинок: фон и фактура сделаны CSS.
- PWA/service worker: базовые файлы могут открываться повторно офлайн.

## Как выложить на GitHub Pages

1. Создай новый репозиторий, например `arabikos`.
2. Загрузи в корень репозитория все файлы из этой папки.
3. Открой **Settings → Pages**.
4. В **Build and deployment** выбери **Deploy from a branch**.
5. Branch: `main`, folder: `/ (root)`.
6. Сохрани. GitHub покажет адрес сайта.

## Где менять слова

Все данные находятся в `data.js`.

Объект слова выглядит так:

```js
{
  id: 'khalaqa',
  ar: 'خَلَقَ',
  bare: 'خلق',
  ru: 'создал',
  type: 'глагол',
  root: 'خ ل ق',
  level: 3,
  form: 'I'
}
```

В `sentenceExercises` у каждого задания есть `required`. Пока пользователь не выучит все слова из этого списка, задание не показывается.

## Важный принцип контента

Учебные предложения и рассказы в MVP являются тренировочными комбинациями из коранической лексики. Они не помечаются как аяты. Для большой базы лучше позже подключить проверенный корпус Корана и хранить для каждого слова ссылки на аяты/суры.
